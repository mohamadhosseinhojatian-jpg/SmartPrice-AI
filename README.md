# 🏡 SmartPrice AI

An intelligent house price prediction project built with Python and Machine Learning.

## 🚀 Features

- House price prediction using Machine Learning
- Data analysis with Pandas and NumPy
- Data visualization and correlation analysis
- Model training and evaluation
- Web interface built with Flask

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Matplotlib

## 📂 Project Structure

- `app.py` — Web application
- `train_model.py` — Train the machine learning model
- `analyze_data.py` — Analyze and visualize data
- `main.py` — Main project script
- `templates/` — HTML templates
- `static/` — Images and visualizations

## 🎯 Goal

The goal of SmartPrice AI is to explore machine learning techniques for predicting house prices and build a practical web application.
